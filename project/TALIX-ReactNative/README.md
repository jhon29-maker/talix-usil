# TALIX — React Native App
## Estructura completa para desarrollador

Esta es la estructura de archivos para la app móvil de TALIX en React Native + Expo.

### Stack tecnológico
- **React Native** con Expo SDK 51
- **Firebase** (Auth + Firestore + Storage)
- **React Navigation** v6
- **NativeWind** (Tailwind para RN)

---

## Instalación

```bash
npx create-expo-app talix-app
cd talix-app
npx expo install firebase @react-navigation/native @react-navigation/bottom-tabs @react-navigation/stack react-native-screens react-native-safe-area-context nativewind
```
